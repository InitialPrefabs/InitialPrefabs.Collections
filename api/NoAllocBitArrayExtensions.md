# NoAllocBitArrayExtensions
## `namespace InitialPrefabs.Collections `

## `ref byte ElementAt(this ref NoAllocBitArray array, int i)`

### Summary
 Returns the byte associated with a specific index you want to access. 

### Param
| Parameter | Description |
|-----------|-------------|
| **array** | The NoAllocBitArray to access. |
| **i** | The location of the bit to access. |

### Returns
**ref byte** - A reference to the nearest byte.
